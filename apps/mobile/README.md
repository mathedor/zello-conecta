# Zello Conecta Mobile

App nativo iOS + Android usando Expo (React Native).

> Inicialização adiada para a **Fase 11** do plano. Quando chegar a hora, este diretório receberá o projeto Expo completo com:
>
> - Expo SDK 52+ com Expo Router
> - NativeWind para estilização compartilhada com a web
> - Bottom tab navigation com botão `+` central expandível
> - Compartilhamento de `@zello/types`, `@zello/validators` e `@zello/db` (via Prisma Accelerate ou API REST)
> - Autenticação com Auth.js
> - Push notifications via Expo Push
> - Build e publicação via EAS (App Store + Play Store)
